# Ryan Micheal — Marketing Portfolio

A responsive one-page personal portfolio for digital marketing and automation services.

## Services featured
- Google Ads
- Meta Ads and TikTok Ads
- Google Merchant Center
- GoHighLevel CRM and workflow automation
- Shopify marketing support

## Run locally
Open `index.html` in a browser. No build step is required.

## Deployment
This is a static site and can be deployed directly on Vercel with the repository root as the project root.

## Personalization before launch
Review the name, service descriptions, Fiverr profile link, and any future case studies or contact details. No performance results or testimonials are claimed on this site.
